# Волжанин — демо-сайт ресторана (Саратов)

Демонстрационная версия сайта ресторана «Волжанин» (Саратов, Большая Затонская ул., 12), собранная на чистом HTML, CSS и JavaScript.

## Особенности демо-версии

- **Архетип дизайна:** Журнальная эстетика (Editorial) с палитрой по реальному интерьеру заведения (молочно-песчаный, волжский синий, коньячный дуб, трамвайный алый, без градиентов).
- **Раздел меню:** крупная заглушка `Н/Д — Меню сейчас недоступно` с готовой структурой данных (`data/data.json` + `js/app.js`) для подключения меню в финальной версии.
- **Отзывы и контакты:** подтверждённые данные с [Яндекс Карт](https://yandex.ru/maps/org/volzhanin/9340339243/) (рейтинг 4,8; 40 отзывов); отсутствующие данные отмечены как `Н/Д`.
- **Бронирование:** форма с клиентской валидацией и модальным уведомлением о демонстрационном режиме.
- **Фотографии:** положите файлы `1.webp`, `2.webp`, `3.webp`, `4.webp` в папку `assets/images/` — пути уже подключены в `index.html` и `data/data.json`.
